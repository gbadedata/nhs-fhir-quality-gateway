How many GP practices does England have?

A quality audit of the NHS Organisation Data Service GP practice file, mapped to FHIR UK Core Organization resources. Snapshot retrieved 2026-11-07. Public organisation data only; no patient records.

Why the answer is 6,162, not 8,193. The file lists every prescribing cost centre: 7,499 non-GP settings (community services, prisons, walk-in centres and others) are set aside by role code. Of the 8,193 GP practice records left, 1,573 are closed, 60 are dormant and 398 active ones are in Wales. The first version of this project counted all 8,193 as current, because it did not recognise the file's INACTIVE and DORMANT status values. Running it on the real file is what exposed that.

Since April 2017, 1,547 English GP practice codes have closed and 57 have opened. ODS warns that closures before April 2017 are incomplete in this file, so the series starts there. A closed code often means a merger rather than a lost service, so this is a measure of consolidation, not of access.

Specification checks

Each GP practice row is checked against the ODS Reference Data Catalogue: 27 columns, code format by nation, mandatory fields, valid dates, close date after open date, and status consistent with the close date. Failing rows go to quarantine.json with reasons.
