# Security policy

Only synthetic data and non-clinical example code belong in this public repository. Do **not** submit NHS Number identifiers, actual patient details, extracts from electronic patient records, confidential staff information, credentials, tokens or private infrastructure addresses.

This educational pipeline has not been independently security-tested or clinically assured and must not be used with real patient data. For a potential security issue, avoid including sensitive data in a public issue; use a private communication channel with the repository maintainer.
